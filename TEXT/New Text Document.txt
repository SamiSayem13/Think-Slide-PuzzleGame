Main Menu
Start Game button to begin playing.
Options button to customize game settings.
Exit button to close the application.
Daily Challenge mode for a unique puzzle every day.
Difficulty Levels

Players can choose from different difficulty modes:

Easy – 3×3 puzzle grid.
Medium – 3×4 puzzle grid.
Hard – 3×5 puzzle grid.
Game Screen Features
Timer
Tracks the total time taken to solve the puzzle.
Stops automatically when the puzzle is completed.
Move Counter
Counts the number of tile moves made by the player.
Helps players improve efficiency.
Pause Button
Temporarily pauses the game.
Freezes the timer until resumed.
Shuffle Button
Randomly rearranges puzzle pieces.
Cancel/Restart Button
Ends the current game or restarts the puzzle.
Returns to the main menu if desired.
Settings (Options Menu)
Audio Control
Enable/disable game sounds.
Vibration Control
Turn vibration feedback on or off.
Theme Selection
Switch between Light and Dark themes.
Customize puzzle appearance.
Score Board
Stores best completion times.
Displays lowest move counts.
Shows top player records for each difficulty level.
Daily Challenge Mode
Generates a special puzzle every day.
Rewards players for completing daily challenges.
Maintains a challenge completion streak.
